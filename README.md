# Love Heart 💖

An international "I Love You" animated heart in Python using Turtle & Tkinter graphics.

Multilingual phrases cascade in a glowing neon sweep across the silhouette of a heart and settle with a warm shimmer.

## Features
- **Multilingual Phrases**: "I love you" written in over 70+ languages from around the world.
- **Vibrant 3-Zone Neon Gradient**: Warm Amber/Gold, Mint Green, and Electric Cyan/Sky Blue.
- **Smooth Animation**: Dynamic entry animation with lift, flash, and floating shimmer effects.

## How to Run

Make sure Python is installed, then run:

```bash
python Iloveu.py
```
